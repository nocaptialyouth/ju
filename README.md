# 주원 적금 통합 & 자산 가계부 대시보드 (V5.0)

구글 스프레드시트(량신) 단방향 자동저장 및 실시간 데일리 금융 특판 위젯이 탑재된 노션 스타일 자산 가계부 대시보드입니다.

---

## ✨ V5.0 주요 업데이트 기능

1. **오입력/잘못 적힌 항목 [🗑️ 삭제] 완벽 지원**:
   - 적금 마스터 & 소유자 현황 테이블 각 행에 삭제 버튼 추가.
   - 가계부 누적 장부, 일정 메모, 병원비 테이블 행 삭제 지원.
   - 웹에서 삭제 시 구글 시트(적금리스트 등)에서도 해당 행이 자동 삭제(`delete_product`, `delete_record`)됩니다.
2. **웹 중심 단방향 자동 저장 (Web ➔ 구글 스프레드시트)**:
   - 웹(`ju-mu-five.vercel.app`)에서 입력/수정/삭제한 내용이 최우선으로 저장되며, 구글 스프레드시트에 실시간으로 백업 저장됩니다.
   - 구글 시트의 구버전 데이터가 웹 화면을 덮어써서 롤백시키는 현상을 원천 방지합니다.
3. **🔥 오늘의 데일리 고금리 적금·예금 특가 & 이달의 추천 (Daily Hot Deals)**:
   - 날짜별로 매일 달라지는 엄선된 고금리 특판 상품(최고 10% 출산/아동 우대, 8% 청년도약, 4% 파킹통장 등) 전시.
   - 카테고리 필터링 및 [다른 특가 보기] 회전 기능.
   - **[+ 내 가계부 등록]** 버튼으로 원클릭 적금 자동 입력 지원.
4. **모바일 반응형 완벽 최적화**:
   - 스마트폰 화면에서도 가로 스냅 스크롤과 유연한 카드/테이블 뷰로 깔끔하게 노출.

## 📁 프로젝트 파일 구성

- **`index.html`** : 대시보드 메인 레이아웃 (KPI 카드, 데일리 특판 위젯, 가계부 DB, 적금마스터, 구글 Apps Script V5.0 매크로)
- **`style.css`** : 노션 감성 프리미엄 스타일링 & 모바일 반응형 완벽 최적화
- **`app.js`** : 단방향 자동 저장 엔진, 삭제 관리, 데일리 특판 로테이션 로직
- **`README.md`** : 프로젝트 안내 및 Apps Script 배포 가이드

---

## 🔗 구글 시트 V5.0 매크로 적용 및 웹앱 배포 방법

1. 대시보드 우측 상단의 **[📋 최신 매크로(V5.0) 복사]** 버튼을 클릭합니다.
2. 구글 스프레드시트 상단 메뉴 **[확장 프로그램] > [Apps Script]**를 열고, 기존 코드를 전체 삭제한 뒤 복사한 코드를 붙여넣고 **저장(💾)**합니다.
3. 오른쪽 상단 **[배포 (Deploy)] > [배포 관리 (Manage deployments)]** 클릭 ➡️ 연필(✏️ 수정) 클릭 ➡️ 버전을 **[새 버전]**으로 선택 후 **[배포]** 클릭! (기존 URL 그대로 즉시 연결됨)
   - *만약 [새 배포]를 누르셨다면, 액세스 권한을 반드시 **`모든 사용자 (Anyone)`**로 지정하고 발급된 웹앱 URL을 웹 상단 **[🔗 새 배포 URL 연결]** 버튼에 붙여넣어 주세요.*
